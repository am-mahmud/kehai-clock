# Kehai Clock – README
## 📌 Overview
Kehai Clock is a modern, elegant product landing website designed to showcase and sell premium clocks inspired by Japanese minimalism.

### This project features:
- A responsive homepage
- Product listing cards
- A functional shopping cart
- A dedicated cart page
- Smooth UI interactions
- vanila CSS-based styling
- Lightweight JavaScript logic for cart management

🛠️ Technology Stack
- HTML5
- Vanilla CSS
- JavaScript (ES6)
- No frameworks, no backend — purely frontend and lightweight

## 🚀 How to Run Locally
- Clone or download the project folder
- Open index.html in any browser
- Navigate freely between product and cart pages
- No backend or configurations required
